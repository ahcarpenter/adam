# Support

## Questions about this repository

Open a [question issue](https://github.com/ahcarpenter/adam/issues/new/choose). Search
the [existing issues](https://github.com/ahcarpenter/adam/issues?q=is%3Aissue) first —
the answer may already be there.

This is a single-maintainer project. Expect a response within 5 business days, best
effort.

## Questions about eve itself

This repository is a starter template, not the framework. For questions about the eve
runtime, its CLI, or its APIs, use the eve documentation at <https://eve.dev/docs> rather
than this issue tracker.

The same applies to the other dependencies wired in here:

| Topic                                   | Where to ask                                       |
| --------------------------------------- | -------------------------------------------------- |
| eve runtime, CLI, tools, channels       | <https://eve.dev/docs>                             |
| AI SDK, providers, model behavior       | <https://ai-sdk.dev/docs>                          |
| Upstash Redis, AgentKit                 | <https://upstash.com/docs/redis/sdks/agentkit/eve> |
| Braintrust traces and evals             | <https://www.braintrust.dev/docs>                  |
| PostHog logs and LLM analytics          | <https://posthog.com/docs>                         |
| OpenTelemetry semantics, `@vercel/otel` | <https://opentelemetry.io/docs>                    |

Ask here when the question is about how _this_ repository wires those pieces together.

## Reporting a bug or suggesting a feature

Use the matching form at
[new issue](https://github.com/ahcarpenter/adam/issues/new/choose). See
[CONTRIBUTING.md](CONTRIBUTING.md) for what makes a report actionable.

## Security

Do not report vulnerabilities in the issue tracker. Follow [SECURITY.md](SECURITY.md).
